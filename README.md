# homebrew-tap

## Overview

DraftAgent is a local MCP server for inspecting, transforming, and converting Microsoft Word documents (OOXML) with high fidelity.

https://draftagent.dev

## Installation

DraftAgent currently supports **macOS only**.

Install DraftAgent with the macOS installer:

```sh
curl -fsSL https://draftagent.dev/install.sh | sh
```

You can also install with Homebrew:
```
brew tap draftagent/tap
brew install draftagent-mcp
```
